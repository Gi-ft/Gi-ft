## My working principles

1. **Start with the decision.** A model is useful when it improves an action, not just a metric.
2. **Respect the data-generating process.** Good predictions begin with reliable collection, clear assumptions, and honest evaluation.
3. **Ship the whole loop.** From source data to database to dashboard, reproducibility matters.
